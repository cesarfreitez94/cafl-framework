# CRIT-02: Operating Flow

Status: not-started

## Session Objective

- [draft] Definir el flujo operativo minimo desde entrada inicial hasta entrega, sin asumir que el pipeline actual es correcto.

## Context

- [accepted] El flujo operativo actual del repo es evidencia secundaria.
- [draft] El flujo condiciona agentes, contratos, gates, evidencias y nivel de autonomia.

## Questions For The Owner

- [open-question] Como deberia comenzar un trabajo real dentro de CAFL?
- [open-question] Que entradas son aceptables: idea breve, entrevista, documento, proceso actual, normativa u otras?
- [open-question] Que fases son indispensables antes de escribir codigo?
- [open-question] En que puntos debe poder detenerse o volver atras el flujo?
- [open-question] Que decisiones puede tomar el sistema sin humano?
- [open-question] Que decisiones requieren aprobacion humana siempre?
- [open-question] Que artefactos son utiles y cuales serian burocracia?
- [open-question] Como debe manejarse scope creep?

## Decisions To Make

- [open-question] Fases minimas del flujo.
- [open-question] Entrada y salida de cada fase.
- [open-question] Reglas de avance, re-trabajo y bloqueo.
- [open-question] Puntos de decision humana o automatica.
- [open-question] Unidad de control: modulo, feature, proyecto, sprint u otra.

## Non-Goals For This Session

- [accepted] No definir comandos ejecutables.
- [accepted] No definir formatos finales de documentos.
- [accepted] No asignar prompts finales a agentes.
- [accepted] No aprobar CI/CD ni RAG.

## Risks If Unresolved

- [draft] Comandos y agentes creados para un flujo equivocado.
- [draft] Handoffs ambiguos y perdida de responsabilidad.
- [draft] Gates ubicados en fases incorrectas.

## Output Format

- [draft] Diagrama textual de fases.
- [draft] Tabla de fase, entrada, salida, responsable conceptual, decision de avance y bloqueo.
- [draft] Lista de dudas abiertas para contratos y gates.

## Acceptance Criteria

- [draft] Cada fase candidata tiene razon de existir.
- [draft] El flujo no depende de herramientas no validadas.
- [draft] Las decisiones automaticas y humanas quedan identificadas como aceptadas o pendientes.
