# Framework Manifest

## Nombre

CAFL Odoo AI Factory Framework

## Version Inicial

0.0.0-source

## Estado

Fuente inicial no instalable.

## Objetivo Runtime Futuro

Instalar agentes, skills, comandos, permisos y plantillas en OpenCode local o global.

## Componentes Fuente

- Agentes fuente en `framework/agents`.
- Skills fuente en `framework/skills`.
- Comandos fuente en `framework/commands`.
- Templates en `framework/templates`.
- Configuracion en `framework/config`.
- RAG en `framework/rag`.
- CI/CD en `framework/ci`.
- Ejemplos en `framework/examples`.

## Componentes Runtime Futuros

- `.opencode/agents/*.md`.
- `.opencode/skills/*/SKILL.md`.
- `.opencode/opencode.json` o configuracion global.
- Comandos segun soporte final de OpenCode.
- MCP para Playwright y servicios RAG si aplica.
