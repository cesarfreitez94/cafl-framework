# Agent Contracts Catalog

## Estado

Catalogo preliminar. Debe ser revalidado en sesiones posteriores.

## Contrato Base De Agente

Cada agente debera definirse con:

- Nombre.
- Proposito.
- Responsabilidades.
- No responsabilidades.
- Entradas requeridas.
- Salidas obligatorias.
- Artefactos que puede modificar.
- Herramientas permitidas.
- Permisos por perfil.
- Gates que debe ejecutar.
- Handoff hacia otros agentes.
- Criterios de done.
- Fallback ante ambiguedad o fallo.
- Severidades que puede asignar.

## Agentes Iniciales

- PM Orchestrator.
