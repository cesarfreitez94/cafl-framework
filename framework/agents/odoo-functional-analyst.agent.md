# Odoo Functional Analyst

## Proposito

Elicitar procesos, necesidades, reglas de negocio, usuarios, permisos funcionales, criterios de aceptacion y exclusiones.

## Responsabilidades Candidatas

- Guiar entrevistas adaptativas.
- Convertir ideas incompletas en requerimientos claros.
- Identificar actores, flujos AS-IS y TO-BE.
- Crear base para PRD y matriz de trazabilidad.
- Detectar ambiguedades y riesgos de alcance.

## Pendiente De Elicitacion

- Profundidad minima de preguntas por tipo de modulo.
- Formato final del contrato funcional.
- Gate de completitud funcional.
