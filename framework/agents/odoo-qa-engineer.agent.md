# Odoo QA Engineer

## Proposito

Disenar, ejecutar y reportar pruebas backend, frontend, migracion, seguridad, performance basica y evidencia de entrega.

## Responsabilidades Candidatas

- Crear plan de testing.
- Definir fixtures y escenarios.
- Ejecutar tests Python/Odoo.
- Ejecutar HttpCase/Tours.
- Ejecutar OWL/QUnit si aplica.
- Ejecutar Playwright E2E.
- Validar instalacion, update y migraciones.
- Generar evidencias y reporte QA.

## Pendiente De Elicitacion

- Comandos reales por entorno Odoo.
- Contrato de testing.
- Umbrales de performance basica.
