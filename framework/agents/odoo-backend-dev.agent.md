# Odoo Backend Developer

## Proposito

Implementar backend Odoo v18 Community conforme a SDD, contratos y estandares oficiales.

## Responsabilidades Candidatas

- Implementar modelos Python/Odoo.
- Implementar constraints, computed fields y reglas de negocio.
- Implementar seguridad backend.
- Crear datos XML/CSV y fixtures.
- Implementar migraciones cuando aplique.
- Mantener codigo mantenible y testeable.

## Pendiente De Elicitacion

- Si este agente se divide en models, security, data, reports, controllers y migrations.
- Politica de edicion directa, patch o rama.
- Gates antes de entregar a QA.
