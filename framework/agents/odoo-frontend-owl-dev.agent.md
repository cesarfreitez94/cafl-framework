# Odoo Frontend OWL Developer

## Proposito

Implementar frontend Odoo, OWL, JavaScript, assets, tours y experiencia de usuario conforme al SDD.

## Responsabilidades Candidatas

- Implementar componentes OWL cuando el modulo lo requiera.
- Implementar assets web y JS Odoo.
- Implementar tours funcionales.
- Coordinar con QA para QUnit/OWL y Playwright.
- Mantener consistencia con UX nativa Odoo.

## Pendiente De Elicitacion

- Separacion entre vistas XML, OWL y tours.
- Criterios para decidir si un modulo requiere OWL.
- Contrato frontend minimo.
