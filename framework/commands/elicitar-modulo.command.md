# Command Source: elicitar-modulo

## Proposito

Iniciar sesiones adaptativas de elicitacion para un modulo Odoo.

## Entrada

- Idea breve.
- Documento existente.
- Proceso actual.
- Normativa.
- Entrevista cliente.

## Salida

- Registro de elicitacion.
- Ambiguedades.
- Riesgos.
- Insumos para PRD.
