# RAG Query Contract

## Proposito

Definir como los agentes consultan conocimiento oficial.

## Entrada Minima

- Pregunta.
- Version Odoo.
- Dominio tecnico.
- Tipo de fuente requerida.

## Salida Minima

- Respuesta resumida.
- Citas.
- Fuente.
- Version/hash.
- Confianza.
- Advertencias.

## Regla

Las decisiones tecnicas relevantes deben citar fuentes oficiales.
